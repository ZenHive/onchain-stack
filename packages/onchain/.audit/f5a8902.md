## Finding (1) — vendored Erigon tree carried ~42k lines of test scaffolding the scrape never reads

The delivery vendored the **entire** upstream `jsonrpc` package — 122 files / ~62k lines — into
`priv/specs/erigon-3578acb3a63d34ca746ff03c5350584c1a4eed0f/jsonrpc`. The scrape, however, only ever
consumes **non-test `.go` files**: `go_files/1` globs `**/*.go` and rejects `_test.go`, and
`method_from_match/3` keeps only declarations whose receiver is `OtterscanAPIImpl` or `TraceAPIImpl`.

That left three provably-unconsumed categories committed as pure repo weight in a library that
advertises "pure Elixir, no native deps, minimalist":

| Removed | Why provably unused by the scrape |
|---|---|
| `testdata/` (18 JSON fixtures, incl. a 26,730-line genesis file) | not `*.go` → never globbed |
| `contracts/` (`*.abi`/`*.bin`/`*.sol` + `gen*.go` codegen) | artifacts not globbed; `contracts/*.go` contain **zero** target receivers (verified) |
| `**/*_test.go` (33 files) | rejected by `go_files/1` |

## Fixed

Pruned the three categories above via `git rm`. The vendored tree drops from 122 files / ~62k lines to
**62 files / 20,230 lines**, retaining all 11 receiver-bearing source files and the rest of the
non-test `.go` package source.

**Output-preserving — verified by static reasoning, not re-run** (the scrape needs a network
tree-sitter grammar download unavailable here): every removed file falls into a category the scrape
demonstrably skips (non-`.go`, `_test.go`, or `.go` with no `Otterscan/TraceAPIImpl` receiver), so a
re-run of `mix onchain.scrape_erigon_methods` regenerates `priv/specs/erigon-methods.json`
byte-identically. No Elixir source was touched; no code references the removed paths
(`grep` over `lib`/`dev`/`test`/docs → none). The `_test.go` files were removed alongside `testdata/`
to avoid leaving dangling fixture references in the vendored package.

## Not done (noted, not acted on)

The 53 remaining non-test `.go` files that lack the two target receivers (~14k lines) are still read by
the scrape but contribute no matches; they could be reduced to the 11 receiver files for a
source-minimal vendor. Left in place to preserve package coherence — that is a design call for the
team, not an audit-forced change.
